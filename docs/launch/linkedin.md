## Body

I built a trip planner I wanted for myself.

You type where you are going. An assistant answers with a day-by-day plan, places, a hotel, and a packing list. Nothing is saved until you tap. You can edit a day, share the trip with family, and add the site to your home screen so it opens like an app.

It is one Expo codebase, with Supabase underneath and the model keys kept on the server. The assistant and the cover pictures run on free allowances, so a busy day can hit a shared limit. When it does, the app says so.

It is free, there is no demo login, and a forgotten password cannot be recovered yet.
